# BAPBAP Build Calculator (unofficial)

A static web calculator for BAPBAP builds: character stats, augments (with levels), per-ability damage against a configurable target, cooldowns and healing. Every calculation step is shown.

- **Data:** `public/data.json` holds configuration values extracted from the game build and traced formula notes. It's generated by `tools/export_data.py` from a local research workspace. No game binaries or assets are included.
- **Engine:** `public/calc.js` (pure functions). Run the focused checks with `node tools/check.mjs`.
- **Run locally:** serve `public/`, e.g. `python -m http.server 5180 --directory public`.
- **Labels:** *Live-verified* means the value was observed in-game. *Code-derived* means it follows from code-traced formulas. Augment effects that aren't modelled are always listed, and the results they affect are marked incomplete.

Not affiliated with BAPBAP. The calculator doesn't rank builds or claim a "best" meta.
